4.1Pre-Modeling Final Check（模型建立前最終確認）

第四章不重新定義 Success、不變更 13 個 Baseline Features，也不變更第三章鎖定的 Train/Test Split 與前處理方法。正式建模前先重建資料、稽核完整性與確認 Modeling Readiness。

Step 1｜Rebuild

SQL 工作資料 11,500 × 29；Baseline X = 11,500 × 13；X_train / X_test = 9,200 / 2,300；Processed = 63 欄。

Step 2｜Integrity Audit

15 項模型資料完整性稽核全部 PASS，涵蓋 Missingness、Structural Missingness、Encoding、Numeric Processing 與 Index Alignment。

Step 3｜Readiness

18 項 Modeling Readiness 稽核 PASS，包含 5-Fold Stratified CV、Required Metrics 與 Test Set Isolation。

CV 防洩漏原則：正式 Cross-Validation 不直接對整份 X_train_processed 做 Fold 切分；Preprocessor 與 Classifier 必須放入同一 Pipeline，以 raw X_train 進入 StratifiedKFold，使每個 Fold 維持 Fold-level Train-only Fit。
4.1 正式判定：Pre-Modeling Final Check = COMPLETE；Modeling Readiness = READY；Test Set = Final Evaluation Only。

4.3Class-Imbalance Treatment and Model Improvement（類別不平衡處理與模型改善）

面對約 4.91 : 1 的 Class Imbalance（類別不平衡），第一階段採單一變因實驗：對原生支援類別權重的模型使用 class_weight="balanced"，其餘資料、前處理、CV Fold 與 Threshold 均不變。

Class Weight 有效改變分類行為

Balanced 版本能提高部分模型的 Class 1 預測數量與 Recall / F1，但往往伴隨明顯增加的 False Positive。

排序能力未實質突破

4 個 Balanced Models 的 PR-AUC 均未高於 No-skill 0.169348，表示改善主要來自分類邊界移動，而非少數類別排序能力提升。

相對角色：Random Forest 為 Relative Class-Weight Treatment Candidate；Logistic Regression 作為 Minority Recall / F1 Reference。
4.3 正式判定：Strong Class-Imbalance Treatment Identified = False；Strong Minority-Class Model Identified = False；Final Best Model Selected = False；Test Set Used = False。

4.6.5～4.6.7：泛化判讀與研究限制

Systematic Deterioration

Final Test 相較 OOF 為 7/7 指標下降；相較 Full CV 亦為 7/7 下降。Test PR-AUC 0.162386 低於 No-skill 0.169130，ROC-AUC 0.477585 低於 0.5。

Weak Independent Generalization

Training 階段的相對領先沒有轉化為足夠的 Independent Test 泛化證據；模型不可宣稱為 Strong Model，也不可直接部署作自動決策。
