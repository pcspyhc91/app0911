Google Play App 成功率預測系統

App Success Prediction Research Prototype（App 成功預測研究原型）

本系統是 Exploratory Decision Support（探索性決策支援）研究原型。預測結果不是 App 成功保證，也不是自動投資或專案核准依據。

1. App Input Form（App 輸入表單）

請填寫12組 App 屬性。
輸入元件、動態欄位控制與正式驗證已整合；按下 Validate Input 後才會判定。
A. Basic Information（基本資訊）
只接受正式36種 Category（類別）。
Unrated 是正式類別，不代表缺失值。
正式 Training Range（訓練範圍）：0.00～399.99。
沒有次要類型時使用 NO_SECONDARY_GENRE。
B. Size and Update（大小與更新）
4. Size Varies with Device（大小因裝置而異）*
選擇「是」時，App Size in MB 會立即停用並建立結構性缺失。
Size Varies=否時必填；正式範圍為5.0～1,998.9 MB。Structural Missingness：Size_MB = NaN（欄位已停用）
固定研究日期範圍：2020-02-05～2026-06-30。
8. Current Version Varies（目前版本因裝置而異）*
只接受明確的否／是選項。
C. Android Compatibility（Android 相容性）
9. Android Version Varies（Android 版本因裝置而異）*
選擇「是」時，最低 Android 版本會立即停用並建立結構性缺失。
Android Version Varies=否時必填。Structural Missingness：Min_Android_Ver = NaN（欄位已停用）
D. Monetization（營利模式）
11. In-App Purchases（應用程式內購買）*
將於後續確定性映射為 Has_In_App_Purchases 0／1。
12. Ad Supported（廣告支援）*
將於後續確定性映射為 Has_Ad_Support 0／1。

* 表示無條件必填或依跨欄位規則判定的必要輸入。

2. Validation Message Area（驗證訊息區）

Validation Status：NOT_EXECUTED
請完成12組輸入後按下 Validate Input；尚未呼叫任何模型。

3. Single-record Model Input（單筆模型輸入）

Model Input Status：NOT_CREATED｜只有 Validation Status=PASS 後才會建立。
